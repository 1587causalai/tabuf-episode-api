\section{先把话说清楚}

\begin{storybox}
我们现在最缺的不是又一个网络结构，而是\textbf{可训练的 episode 从哪来}。
这篇手册是写给自己的：先把生成语义钉住，再改代码。
怎么调服务、字段范围，都不在这里。
\end{storybox}

工作方式不变：先改这篇文档，再改代码。绿=已锁定，黄=还没锁，灰=第零版故意关掉。

\begin{lockbox}
第零版只生成\textbf{观测世界}。拿到的是 episode（完整表 + 两张 mask），
不是 DAG，也不是潜变量 $\uu_i$。
\end{lockbox}

\section{我们到底要喂给网络什么}

表格基础模型的训练对象，常常被说成「一张表」。这对 \TabUF{} 不够用。
网络真正要学的，是：\textbf{已经看见一部分格子之后，去填另一部分格子}。

所以训练样本不是表，是 \textbf{episode}：一张完整表，外加 missing 与 query 两张 mask。
一次请求可以要多条 episode，但一条 episode 仍然是\textbf{一个生成世界}，不是一个训练 batch。
没有单独的 $y$。真值就在完整表的 query 格子上。

为什么可以是格子级，而不是永远整列标签？
因为 \TabUF{} 要能回答的，不只是「这个人缺一个标签」，
还包括「这个特征在这些人身上会是什么」。
推荐场景里，这几乎是默认形态。

\begin{lockbox}
训练样本是 episode：完整表 + missing + query。
不是整张裸表，也不是一个 DAG。网络不准看见 $u_i$。
\end{lockbox}


\section{episode 不是 batch：两个旋钮不要混}

这两个词最容易被当成一回事。它们不是。

\paragraph{episode 是世界。}
一条 episode 是一次独立的数据生成：自己的总体 $U$、自己的特征 token DAG、自己的列类型、自己的格子、自己的 mask。
第 $e$ 条用 $\mathrm{seed}+e$。
\texttt{n\_episodes} 问的是：这次要几个这样的世界。默认 $8$。

\paragraph{batch 是堆叠。}
训练一步常常需要把好几张表叠成 $(\texttt{batch\_size}, n, d)$。
GPU 做不到「第一张 $20$ 列、第二张 $200$ 列」直接 \texttt{stack}。
所以 \texttt{batch\_size} 是打包约束：\textbf{同一组里} $n$、$d$、$k$ 锁成一样；
下一组才重新抽 $d$、$k$（当请求里它们是 \texttt{null} 时）。
\texttt{n\_units} 始终是请求参数，不抽。

\paragraph{默认为什么是 $1$。}
默认 \texttt{batch\_size}=1，意思是每条 episode 单独成组，于是每条自己抽 $d$、$k$。
这才跟「不同的 episode 是不同的世界」一致。
只有当你明确要一步吃 $8$ 张同形状表时，才把 \texttt{batch\_size} 写成 $8$。
那时 $8$ 条仍然是 $8$ 个不同世界（$U$、DAG、列类型都重抽），只是张量尺寸相同。

\paragraph{一次调用里什么会重抽。}
\begin{center}
\begin{tabular}{@{}llp{8.6cm}@{}}
\toprule
量 & 何时重抽 & 说明 \\
\midrule
$n$（\texttt{n\_units}） & 不抽 & 请求旋钮，整个调用共用 \\
$d$、$k$ & 每个 \texttt{batch} 一次 & \texttt{null} 才抽；组内共用，下一组再抽 \\
总体 $U$、DAG、$\mathbf{t}_j$、列类型、格子、mask & 每条 episode 一次 & 这才是「不同的世界」 \\
\bottomrule
\end{tabular}
\end{center}

三个容易错的读法：
\begin{itemize}
  \item \texttt{n\_episodes} \textbf{不是} \texttt{batch\_size} 的别名。
  \item \texttt{batch\_size}=8 不是「复制同一张表 8 份」，是 8 个世界、同一套 $(n,d,k)$。
  \item 写死 \texttt{n\_features} 以后，所有组的 $d$ 都不再抽，只剩 $k$ 还按组抽（若 \texttt{unit\_dim} 仍是 \texttt{null}）。
\end{itemize}

例子（调用合同见 \texttt{docs/api.pdf}）：
\texttt{n\_episodes}=16、\texttt{batch\_size}=8
$\to$ 两组。组内 8 张表可 \texttt{stack} 成 $(8,n,d)$；两组的 $d$、$k$ 一般不同。
默认 \texttt{n\_episodes}=8、\texttt{batch\_size}=1
$\to$ 8 组、8 套形状，不能直接叠。

\begin{lockbox}
\texttt{n\_episodes}：几个世界。
\texttt{batch\_size}：几个世界共用一套 $(n,d,k)$，好叠成张量。
默认每条世界自己一套形状。
\end{lockbox}

\section{来源是通道，不是 DiscoSCM 的方言}

共享的只有 episode 信封：完整表 + 两张 mask。
通道由生成器名字区分，默认是 discoscm。
\textbf{不要}把每一条通道都读成「先抽总体再填格子」。

名字会出现在下面的解释里——discoscm、scm、sklearn、openml、recsys——
那只是在说世界从哪来，不是在列一份调用目录。

\begin{lockbox}
各来源语义独立。信封共享，生成故事不共享。
\end{lockbox}

\section{三种世界}

行的含义看来源，不能混着讲。

\paragraph{DiscoSCM。}
行\textbf{就是} unit，每人有潜变量 $u_i$。
先抽总体（位置--尺度混合：$M$ 按 $1/M$ 落在 $1\ldots\lfloor\sqrt{n}\rfloor$，分量独立 Gaussian / Cauchy），
再在特征 token $\mathbf{t}_j$ 上抽单位球 SCM
（稀疏骨架 + 星枢纽 DAG、父混合后非线性 $\varphi$、异质噪声），
再用 unit-specific 线性响应律 $g_j(\langle u_i,\mathbf{t}_j\rangle, e)$ 填格子（$K$ 类为线性 softmax）。
这是 \Disco{} 自己的世界 \cite{gong2024discoscm}。公式在附录~\ref{app:disco}。

\paragraph{文献 SCM / sklearn / OpenML。}
行是 i.i.d.\ 观测（或实体行），\textbf{没有} unit token。
文献里的特征 SCM（TabPFN / TabICL 风格）先抽一张特征 DAG，再抽样本，
然后指定一个预测节点——我们把最后一列当作 $y$。
sklearn 分类/回归/真实表同样是「最后一列是标签」。
低秩矩阵是例外：没有标签，按格子出题。细节在附录 B--E。

\paragraph{推荐。}
行是 user，列是 item。未观测就是 missing；query 是已观测评分的子集。
附录~\ref{app:recsys}。

\begin{lockbox}
只有 discoscm 把行当成带 $u_i$ 的 unit。
scm / sklearn / OpenML 不是 DiscoSCM。recsys 也不是。
\end{lockbox}

\section{Compiler：出题，不改世界}

无论世界从哪条通道来，Compiler 合同相同：

\begin{itemize}
  \item \texttt{values} 保持完整，不因 mask 挖空。
  \item missing 与 query 独立抽取，\textbf{允许重合}。
        $Q\cap M$ 是缺失填补，$Q\setminus M$ 是普通预测。
        网络可见的上下文是 $\neg M\wedge\neg Q$。
  \item 没有额外的 $y$ 字段，也没有 \texttt{y\_input} / \texttt{y\_query}。
\end{itemize}

默认比例看来源画像，不在正文里背。表在附录~\ref{app:masks}。

旧合同「$C$ 与 $Q$ 把全表划成互补的两块」已经作废。
现在世界可以先缺格子，再在剩下的格子上出题；两张 mask 不是划分。

\begin{lockbox}
Compiler 不改世界里的数。真值用完整表在 query 处取值。
$M$ 与 $Q$ 可重合。训练路径禁止 $u_i$ 进网。
\end{lockbox}

\section{已锁定，和故意以后再做}

\begin{lockbox}
\begin{itemize}
  \item 观测 episode；不干预、不重抽反事实噪声。
  \item 多通道，共享信封。
  \item DiscoSCM：先混合总体，再特征 token 单位球 SCM（hub DAG、$\varphi$、异质噪声），再 unit-specific 填格。
  \item 其它通道按自己的世界生成，再进同一 Compiler。
  \item $R$ 与 $S$ 不许静默平均成一个头。现在只训 $R$。
\end{itemize}
\end{lockbox}

\begin{laterbox}
干预 $do(\mathbf{x})$；S 臂监督；把网络写进这个仓库；
OpenML / 推荐缓存（接口已占位）。
\end{laterbox}

\begin{openbox}
同一个总体能否跨 episode 复用；
\texttt{query\_frac} 是否 curriculum；
无限 DataLoader 放在这个仓库还是训练仓库。
\end{openbox}

\section{DiscoSCM：总体与 unit-specific 律}
\label{app:disco}

这一附录是 \Disco{} 通道的手册。其它通道不要套用这里的词。

\subsection{为什么必须先抽总体}

常见表格合成器骨子里是：每一行独立地再抽一遍机制。
行与行可以相关，但「这一行是谁」往往没有单独的身份。

\Disco{} 把随机性劈成两截 \cite{gong2024discoscm}：
$U$ 是 unit selection，一次实现 $U=u$ 就是一个个体；
$\mathbf{E}$ 是这个个体身上的外生噪声，独立于 $U$。
结构方程是 unit-specific 的：
\begin{equation}
  v_{\ell} \;\leftarrow\; f_{\ell}(pa_{\ell},\, e_{\ell};\, u).
  \label{eq:unit-law}
\end{equation}
同一个 $f_{\ell}$，换一个 $u$，响应可以不同。
$u$ 钉住的是个体，不是行号。

生成顺序因此钉死：先从总体 $\Pi$ 实现 $\{\uu_i\}_{i=1}^{n}$，
再按 \eqref{eq:unit-law} 填他们在各个 feature 上的取值。
不能倒过来。

一个小例子。总体里有两种人：一种对折扣敏感，一种几乎不买账。
如果每一行都重新抽一套机制，网络学到的是行间噪声花样，
不是「同一种人在不同列上应当怎么响应」。
推荐、Uplift、个性化决策问的都是后者。没有钉住的 $u$，反事实臂没有主语。

第零版\textbf{不}做干预，\textbf{不}重抽反事实噪声。只抽一次观测噪声。

\subsection{Prior}

总体是位置--尺度混合，不是单团 $\mathcal{N}(0,I_k)$。
混合数
\begin{equation}
  M \in \{1,\ldots,\lfloor\sqrt{n}\rfloor\},\qquad
  P(M=m) \propto 1/m.
\end{equation}
等权时每类大约至少 $\sqrt{n}$ 个人。$P(M)\propto 1/m$ 让多数 episode 仍是 1--4 类，大表偶尔才顶到帽。
权重 $\pi\sim\mathrm{Dirichlet}(1_M)$。每个分量独立抽族：Gaussian 或 Cauchy。
$M=1$ 时中心在原点、尺度 $1$，高斯分量就是原来的 $\mathcal{N}(0,I_k)$，Cauchy 分量是标准 Cauchy。
$M>1$ 时中心放在拉开的球面上，尺度对数正态，避免簇叠成一团。
Cauchy 分量的中心是位置参数，不是均值。
$k$ 是 \texttt{unit\_dim}，个体嵌入维数，不是网络宽度。默认 null，从先验抽样（众数约 $16$，支持 $[2,1024]$；这组混合是手工定的）。
$\{\uu_i\}$ 合起来就是这一集自己的总体切片。每条 episode 各自抽一回。

列数 \texttt{n\_features} 缺省时从先验抽样（众数约 $20$，支持 $[2,1000]$）：
以 $0.80$ 从 $\log\mathcal{N}(\log 20, 0.50^2)$ 抽取并 clip 到 $[4,64]$，
以 $0.15$ 从 $[20,200]$ 对数均匀抽取，以 $0.05$ 从 $[200,1000]$ 对数均匀抽取，
最后 clip 到 $[2,1000]$。显式整数则直接用（同样 clip）。
\texttt{unit\_dim} 缺省时从先验抽样（众数约 $16$，支持 $[2,1024]$）：
以 $0.80$ 从 $\log\mathcal{N}(\log 16, 0.45^2)$ 抽取并 clip 到 $[2,64]$，
以 $0.15$ 从 $[32,256]$ 对数均匀抽取，以 $0.05$ 从 $[256,1024]$ 对数均匀抽取。
这组混合是手工定的。
列类型按 \texttt{type\_weights} 多项抽样，默认权重
$70{:}5{:}10{:}5{:}5$（numeric / ordinal / binary / categorical / high\_cardinality）。
每列以 \texttt{independent\_frac}（默认 $0.05$）的概率\textbf{不进}特征 token DAG：
无父节点，也不被当作父节点，并与 $u$ 断开，改抽原来的类型边缘。

\subsection{World：特征 token 单位球 SCM，再按列类型填格}

格子 $(i,j)$ 是第 $i$ 个 unit 在第 $j$ 个 feature 上的取值。
SCM 作用在特征 token $\mathbf{t}_j\in\mathbb{R}^k$ 上，\textbf{不是}作用在格子值 $Y$ 上。
填格仍用原来的类型特异 $g_j$：把旧的 $\mathbf{w}_j$ 换成 $\mathbf{t}_j$，
同一个 $\uu_i$ 贯穿这一行（独立列除外）。
$\sigma$ 是观测噪声标准差，默认 $0.3$。

\paragraph{DAG。}
对非独立列：随机置换作为拓扑序。先抽稀疏骨架：典型父节点上限 $\texttt{typical\_cap}=6$
（\texttt{max\_parents=null}），入度 $k\sim\mathrm{Poisson}(\lambda=2.2)$ 再 clip 到上限，
从拓扑前驱按优先连接 $P(p)\propto \mathrm{outdeg}[p]+1$ 抽 $k$ 个父节点。
这是\textbf{大概率}的常见图。另以概率 $0.15$（或请求 \texttt{graph\_family=star}）叠 $1$--$2$ 个显式星：
抽 $\mathrm{frac}\sim\mathrm{Unif}[0.45,0.85]$，
前三分之一一个 out-hub、后三分之一一个 in-hub，使极少数节点有很多父或很多子。
\texttt{graph\_family=sparse} 强制不叠星。
请求里显式给出 \texttt{max\_parents} 时，该整数是所有节点的硬上限，不叠星。
\texttt{dag\_edge\_p} 是遗留字段：仍接受、仍写入 \texttt{response\_law}，
但不再按 Bernoulli$(p)$ 连边。独立列不出现在这张 DAG 里。

\paragraph{谁先出现：根节点。}
拓扑序 $\pi$ 是非独立列的随机置换。$\pi$ 上第一个节点的前驱是空集，所以\textbf{一定是根}。
其后节点的入度 $k\sim\mathrm{Poisson}(2.2)$，抽到 $0$ 也会成为根（Poisson$(2.2)$ 下大约 $11\%$）。
星形叠加可能给后面的点补上 hub 父节点，但补不了 $\pi$ 里那些还没有前驱的点。
独立列不进这张图，没有 token，不算根。

根没有东西可继承。对该列噪声族在 $\mathbb{R}^k$ 上抽一条向量，拧到单位球上就结束：
\begin{equation}
  \eta_j \sim \mathrm{NoiseFam}_j,\qquad
  \mathbf{t}_j \;=\; \mathrm{normalize}(\eta_j),\qquad
  \varphi_j=\mathrm{identity}.
\end{equation}
高斯根是球面上的均匀方向；$t$ / Cauchy 根更爱贴轴、出尖方向。
这就是因果图里「最开始那一批」。

\paragraph{Token SCM：有父之后。}
$\beta$ 是父节点混合权重（L1 归一，$\sum|\beta|=1$）；效应强度是遗传力 $\alpha$（默认 $0.75$）。
相对 $|\beta|$ 先按 NOTEARS/LiNGAM 惯例从 $\mathrm{Unif}[\beta_{\min},\beta_{\max}]$（默认 $[0.5,2]$）抽取、符号独立取 $\pm 1$，再 L1 归一；单父时 $\beta=\pm 1$。
$\mathrm{Unif}[0.5,2]$ 只决定多父时的相对比例，normalize 之前。
不要再用 $\mathcal{N}(0,0.4^2)$。
有父时按拓扑序先线性混合再过非线性
\begin{equation}
  \mathbf{s}^{\mathrm{raw}}_j \;=\; \sum_{p\in\mathrm{pa}(j)}\beta_{jp}\,\mathbf{t}_p,\qquad
  \mathbf{s}_j \;=\; \mathrm{normalize}\bigl(\varphi_j(\mathbf{s}^{\mathrm{raw}}_j)\bigr),
\end{equation}
$\varphi_j$ 以 $0.50/0.20/0.20/0.10$ 抽
$\{\mathrm{identity},\tanh,\mathrm{leaky\_relu},\sin\}$
（leaky ReLU 负半轴系数 $0.2$）。
再抽与 $\mathbf{s}_j$ 正交的创新：先从该列噪声族抽 $\eta_{\mathrm{raw}}$，
$\eta_j=\mathrm{normalize}\bigl(\eta_{\mathrm{raw}}-\langle\eta_{\mathrm{raw}},\mathbf{s}_j\rangle\mathbf{s}_j\bigr)$。
遗传力 $\alpha=\texttt{token\_heritability}$ 截到 $(0.05,0.95)$，默认 $0.75$：
\begin{equation}
  \mathbf{t}_j \;=\; \mathrm{normalize}\bigl(\alpha\,\mathbf{s}_j + \sqrt{1-\alpha^2}\,\eta_j\bigr).
\end{equation}
因此 $\varphi=\mathrm{identity}$ 时 $\langle\mathbf{t}_j,\mathbf{s}_j\rangle\approx\alpha$；
其它 $\varphi$ 会把子--父余弦从 $\alpha$ 上挪开一点。

\paragraph{噪声族。}
每列（含根节点与独立列）以 $0.50/0.30/0.20$ 抽
$\{\mathrm{gaussian},\,t,\,\mathrm{Cauchy}\}$；$t$ 的自由度在 $\{3,4,5,6\}$ 上均匀。
该族用于：根 token、正交创新 $\eta_{\mathrm{raw}}$、以及 numeric / binary / ordinal
的观测噪声 $e_{ij}$（乘 $\sigma$，student-$t$ / Cauchy \textbf{不}再标准化到方差 $1$）。
独立 numeric 为 $\mu + \sigma_j\cdot\mathrm{draw}$。
类别列用线性 softmax（见下），观测噪声 $e$ 不进类别 logits。

\paragraph{数值。}
$Y_{ij}=\mathrm{scale}_j\,\langle \uu_i,\mathbf{t}_j\rangle+\mathrm{shift}_j+e_{ij}$。
独立列则是列级高斯边缘。

\paragraph{二值。}
潜变量阈值：$\mathbf{1}\{\langle \uu_i,\mathbf{t}_j\rangle+e_{ij}>0\}$。
独立列是 Bernoulli。

\paragraph{有序。}
ordered probit：在 $\langle \uu_i,\mathbf{t}_j\rangle+e_{ij}$ 上切 $K_j-1$ 个阈值，
$K_j\in\{3,\ldots,8\}$。

\paragraph{多值 / 超多值。}
列 token 仍是 $\mathbf{t}_j$。类嵌入取
\begin{equation}
  C_c \;=\; a_c\mathbf{t}_j + 0.25\, r_c,\qquad r_c \perp \mathbf{t}_j,
\end{equation}
其中 $r_c$ 落在 $\mathbf{t}_j$ 的正交补上（因此共享方向钉在 $\mathbf{t}_j$；超多值时 $a_c$ 尺度更散）。
响应在 $u$ 上是线性的：
\begin{equation}
  \mathrm{logits}_i \;=\; \uu_i C^\top,\qquad
  p_i \;=\; \mathrm{softmax}(\mathrm{logits}_i),\qquad
  Y_{ij}\sim\mathrm{Categorical}(p_i).
\end{equation}
$\varphi$ 只作用在 token SEM 的 $\mathbf{s}^{\mathrm{raw}}$ 上，不作用在 $Y$。
独立列是 Dirichlet-多项边缘。

离散格点是 $\{0,\ldots,K_j-1\}$ 的整数。数值格是 float。
世界填满之后，掩码不许回头改 $Y_{ij}$。

\subsection{Compiler 在 DiscoSCM 上的默认}

格子级。默认 $P(M)=0.05$、$P(Q)=0.15$，独立抽取，并集不必是 $20\%$。
\texttt{query\_mode=any\_cell}。\texttt{uses\_unit\_token=true}。
\texttt{n\_units} 默认 $1000$（API 上限 $4096$）。
\texttt{n\_features} 默认 \texttt{null}（从先验抽样，众数约 $20$，支持 $[2,1000]$）。
\texttt{unit\_dim} 默认 \texttt{null}（从先验抽样，众数约 $16$，支持 $[2,1024]$）。

\texttt{return\_mechanism} 或 \texttt{debug} 时带
\texttt{population}（含混合总体 \texttt{mixture} / \texttt{assignment} / \texttt{representations}）和
\texttt{response\_law}（DAG 的 \texttt{parents} / \texttt{betas}、
\texttt{dag\_edge\_p}（遗留） / \texttt{max\_parents} /
\texttt{typical\_max\_parents} / \texttt{max\_in\_degree} /
\texttt{hubs} / \texttt{out\_hubs} / \texttt{in\_hubs} / \texttt{activations} / \texttt{noise\_families} /
\texttt{n\_features\_sampled} / \texttt{token\_heritability} /
\texttt{beta\_min} / \texttt{beta\_max}、
特征 token $\mathbf{t}_j$、以及逐列 $g_j$ 的参数，含 \texttt{noise\_family}）。
默认响应仍省略这些块。
它们描述表从哪来，不是给网络的输入。形状见附录~\ref{app:payload}。

\section{文献 SCM（TabPFN 风格 ANM）}
\label{app:scm}

\textbf{不是} DiscoSCM。没有 unit token。行是 i.i.d.\ 观测样本。

在 $d$ 个特征上抽一张随机 DAG，按拓扑序生成加性噪声 SCM：
根节点是噪声；否则父节点的线性组合或 $\tanh$，再加 $\mathcal{N}(0,\sigma^2)$。
最后一列指定为预测目标 $y$（文献惯例：先抽 SCM，再挑一个节点来预测）。

这里的行数旋钮表示 $n_{\mathrm{samples}}$。
\texttt{unit\_dim} / \texttt{type\_weights} / \texttt{independent\_frac} / \texttt{population}
不适用，响应里不会出现。

默认 \texttt{query\_mode=label\_cell}，\texttt{missing\_frac=0.05}。
机制在字段 \texttt{mechanism}，键为
\texttt{framework}、\texttt{edges}、\texttt{node\_fn}、\texttt{target\_col}。
\texttt{target\_col}=$d-1$。这是特征 DAG，不是个体响应律。
不要读 \texttt{population} / \texttt{response\_law}。

\section{sklearn 合成}
\label{app:sksynth}

行是 i.i.d.\ 样本。没有 unit token。没有 population。
机制在 \texttt{mechanism}，带 \texttt{maker}。
别名仍可用：省略子名则随机抽一个 maker，并套用该 maker 的画像。

\subsection{sklearn\_make\_classification}
最后一列二值 $y$。默认 \texttt{label\_cell}，missing $0.05$。

\subsection{sklearn\_make\_regression}
最后一列连续 $y$。默认 \texttt{label\_cell}，missing $0.05$。

\subsection{sklearn\_friedman1}
Friedman \#1。最后一列连续 $y$。默认 \texttt{label\_cell}，missing $0.05$。

\subsection{sklearn\_low\_rank}
低秩矩阵。\textbf{没有}标签列。默认 \texttt{any\_cell}，missing $0.05$ / query $0.15$，按矩阵补全出题。

\section{sklearn 真实表}
\label{app:skreal}

行是实体行（\texttt{entity\_row}），不是 unit。
对原表按请求的行数、列数子采样，保留最后一列。
默认 \texttt{label\_cell}，missing $0.05$。

\texttt{sklearn\_iris}、\texttt{sklearn\_wine}、\texttt{sklearn\_breast\_cancer}：最后一列类别。
\texttt{sklearn\_diabetes}：最后一列连续靶。
别名套用被抽中的真实表。

\section{OpenML 占位}
\label{app:openml}

监督表。行是 \texttt{entity\_row}。默认 \texttt{label\_cell}，missing $0.05$。
缓存接上之前这条通道还不能出表。不要用 DiscoSCM 的词描述它。

\section{推荐占位}
\label{app:recsys}

User$\times$Item 矩阵。行含义是 \texttt{user}。
未观测格是 missing；query 用 \texttt{any\_cell}，按 $0.15$ 抽格子。
缓存接上之前这条通道还不能出表。

\section{机制 payload 形状}
\label{app:payload}

线上字段名以 \texttt{docs/api.pdf} 为准。这里只讲含义：这些块描述表从哪来，不是网络输入。

discoscm 在 \texttt{return\_mechanism} 或 \texttt{debug} 时给两块：
\texttt{population} 含 \texttt{id}、\texttt{n\_units}、\texttt{unit\_dim}、
\texttt{prior}（\texttt{location\_scale\_mixture}）、
\texttt{mixture}（$M$、\texttt{weights}、逐分量 \texttt{family}/\texttt{location}/\texttt{scale}）、
\texttt{assignment}、
\texttt{representations}（行 $i$ 是 $u_i$）；
\texttt{response\_law} 含 \texttt{form}（\texttt{feature\_token\_linear\_scm}）、
\texttt{type\_weights}、\texttt{column\_independent\_prob}、
\texttt{dag\_edge\_p}（遗留）、\texttt{max\_parents}、
\texttt{typical\_max\_parents}、\texttt{max\_in\_degree}、
\texttt{token\_heritability}、
\texttt{beta\_min}、\texttt{beta\_max}、\texttt{n\_features\_sampled}、
\texttt{parents}、\texttt{betas}、\texttt{tokens}（独立列为 null）、
\texttt{activations}、\texttt{noise\_families}、\texttt{hubs} / \texttt{out\_hubs} / \texttt{in\_hubs}、
以及逐列 \texttt{columns}（含 \texttt{noise\_family} / \texttt{noise\_df}）。
默认响应省略这些块。没有 \texttt{mechanism} 字段。

scm 给 \texttt{mechanism}：\texttt{framework=ANM-SCM}、\texttt{edges}、
\texttt{node\_fn}、\texttt{target\_col}。没有 population / response\_law。

sklearn 给 \texttt{mechanism}：\texttt{framework} 加 \texttt{maker} 或 \texttt{dataset}。
没有 population / response\_law。

训练 DataLoader 不准吃这些块。
