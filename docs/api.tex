\section{这份文档管什么}

运输层。生成数学不在这里。

\texttt{POST /v0/episodes} 返回 $n$ 条 episode。共享的只有信封：完整表
\texttt{values}，外加 \texttt{missing\_mask} / \texttt{query\_mask}。
没有单独的 $y$。真值就在 \texttt{values} 里。

各 \texttt{source} 是不同通道，不是 DiscoSCM 的变体。
DiscoSCM 公式见 \texttt{docs/data-generation.pdf} 附录~A。
其它通道的语义在那份文档的附录 B--F；本文只写字段归属和怎么调。
默认数字、JSON 样例、字段表，全部在本文附录，不进正文。

机器可读对照：\texttt{/docs}、\texttt{/redoc}、\texttt{/openapi.json}、
\texttt{GET /v0/sources}。

\section{信封}

一次请求要 $n_{\mathrm{ep}}$ 张表，\texttt{source} 选生成器，默认 \texttt{discoscm}。

每条 episode 有一张完整表。Compiler 只盖两张独立的 mask，不改格子上的数。
\texttt{n\_units} 在线上是行数旋钮：只有 discoscm 把行当成 unit；
scm / sklearn 里它就是样本数。

训练只吃 \texttt{table}。不要把 \texttt{population}、\texttt{response\_law} 或
\texttt{mechanism} 喂进网络。

\section{字段分家}

请求里有两类字段。

\textbf{共享}（所有来源都认）：行数 \texttt{n\_units}、列数 \texttt{n\_features}、
\texttt{seed}、\texttt{n\_episodes}、\texttt{source}、缺失/query 比例与
\texttt{query\_mode}、\texttt{return\_mechanism}。
别名还认 \texttt{source\_name}。

\textbf{只对 discoscm 生效}：\texttt{unit\_dim}、\texttt{type\_weights}、
\texttt{independent\_frac}、\texttt{debug}。
其它来源静默忽略。\texttt{sigma} 只对 discoscm 与 scm 有噪声含义。

\texttt{return\_mechanism=true} 时，字段名看来源：
discoscm 给 \texttt{population}+\texttt{response\_law}；
scm / sklearn 给 \texttt{mechanism}，\textbf{不会}带 population / response\_law。
不要在 scm 上读 DiscoSCM 的块。

完整范围表见附录~\ref{app:fields}。

\section{来源是通道，不是方言}

canonical 名：
\texttt{discoscm}，
\texttt{scm}，
\texttt{sklearn\_make\_classification}，
\texttt{sklearn\_make\_regression}，
\texttt{sklearn\_friedman1}，
\texttt{sklearn\_low\_rank}，
\texttt{sklearn\_iris}，
\texttt{sklearn\_wine}，
\texttt{sklearn\_breast\_cancer}，
\texttt{sklearn\_diabetes}，
\texttt{openml}，
\texttt{recsys}。

别名 \texttt{sklearn\_synthetic} / \texttt{sklearn\_real} 仍可用。
目录、行含义、默认 mask：\texttt{GET /v0/sources}，表在附录~\ref{app:masks}。

一句话归属（细节不在正文）：
\begin{itemize}
  \item discoscm：行是 unit，有 $u_i$。机制字段是 population / response\_law。
  \item scm：特征 DAG 上的 i.i.d.\ 行，无 unit token，最后一列是预测目标。机制是 DAG。
  \item sklearn 合成 / 真实表：i.i.d.\ 或实体行。多数最后一列是标签；low\_rank 没有标签。
  \item openml / recsys：占位，501。
\end{itemize}

\section{服务地址与约定}
\label{app:addr}

本机 \url{http://127.0.0.1:8787}。
公网隧道（会变）\url{https://spotlight-predicted-heaven-clips.trycloudflare.com}。
无鉴权。单次最多 32 episode。

HTTP/1.1，JSON，UTF-8。可复现性靠 \texttt{seed}。掩码是 JSON boolean。
\texttt{values} 不因 mask 挖空。没有 \texttt{y\_query} / \texttt{y\_input} / \texttt{context\_mask}。

\section{\texttt{GET /v0/sources} 画像}
\label{app:catalog}

每条来源（canonical + 别名）返回：
\texttt{status}（ready / placeholder），
\texttt{family}，
\texttt{row\_meaning}（unit / iid\_sample / entity\_row / user），
\texttt{query\_mode}、\texttt{missing\_frac}、\texttt{query\_frac}，
\texttt{uses\_unit\_token}，
\texttt{request\_fields\_used} / \texttt{request\_fields\_ignored}，
一句 \texttt{note}（除 discoscm 外不用 DiscoSCM 黑话）。

\section{错误码}

200 成功。422 字段越界 / 未知 source。501 占位未缓存。405 / 404 方法或路径不对。
格子太大被 \texttt{le=} 拦在 422。
